By default, arguments are passed to functions by value. Which means functions get a new copy of argument. If we want to update the argument in memory, we need to pass the pointer (argument's address) to functions. To get the address of a variable, we use "&" sign as prefix on variable names.

To address the value of a pointer,  we use dereference sign "*" as prefix on variable name. An array variable can be use as a pointer and points to the first element of array.
